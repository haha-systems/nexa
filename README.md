# Nexa

Nexa is a proposed general-purpose, AI-first language with typed component composition, reusable memories, and authorized effects.

The agreed design and first implementation plan are in [the language specification](docs/nexa-language-specification-0.3.md) and [the slice plan](docs/nexa-functional-slice-plan.md). The reference implementation will use Rust.

The first target is Slice 0: compose trim, greet, and stdout memories into an inspectable program, then save and reuse that composition.
